# Verdant - AI-Powered Workplace Productivity Assistant

## Project Overview
Verdant is a single integrated AI dashboard that solves real-world workplace problems. It helps professionals save time on emails, research, and daily tasks by using responsible AI. The purpose is to demonstrate practical AI implementation, prompt engineering, and ethical AI use with a modern user-friendly interface.

Live Demos:
- Lovable: https://workplace-genius-bot.lovable.app
- GitHub Pages: https://gwajunathi-rgb.github.io/AI-Productivity-Assistant/

## Features Implemented (4/3 Required)
1. **Smart Email Generator** - Generates professional, friendly, and formal emails using prompt engineering (tone selection + context-aware prompts)
2. **AI Research Assistant** - Summarizes topics and provides key insights to solve workplace research problems
3. **AI Chatbot Assistant** - Instant workplace Q&A helper
4. **Dashboard with Recent Activity** - Single application view that brings all tools together

## Technologies and Tools Used
- **Frontend:** HTML, CSS, JavaScript, React (via Lovable)
- **AI Tools:** Lovable AI for prompt engineering and UI generation
- **Version Control:** GitHub (2 verified commits)
